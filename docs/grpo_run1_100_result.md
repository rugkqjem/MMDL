# GRPO run1 (100스텝) 결과

## 1. 학습 설정
- 재파일럿(token_truncate) `checkpoint-20`에서 이어서 100스텝까지 학습함. 설정은 재파일럿과 동일함.
  - LoRA r16, lr 1e-5 (warmup 5 이후 고정), DAPO loss, beta 0
  - 문제당 응답 8개, 최대 응답 길이 8192
  - 보상: 정답 1 / 오답 0 / 잘림 −0.5
- 학습 시간: 21~100스텝에 약 11시간 20분(A100 1장), 스텝당 평균 약 8.5분
- 학습량: 100스텝 ≈ 0.5에폭 (780문제 중 약 400문제를 1회씩 학습, 1에폭 = 195스텝)

## 2. 학습 중 지표 (새로 생성하는 스텝 기준, 4스텝마다 응답 128개)
- 잘림 비율: 21~89스텝 동안 6~24% 사이에서 오르내림 → 줄어드는 추세 없음
- 정답 비율: 41~61%로 문제 구성에 따라 오르내림
- 평균 응답 길이: 2900~4200 토큰, 후반에 오히려 조금 길어짐

## 3. MMMU-val 평가 결과 (900문항, 기존 평가 설정과 동일)

| 모델 | 점수 | 차이 | 정답 수 | 잘린 응답 | 평균 출력 토큰 |
|---|---|---|---|---|---|
| 베이스라인 | 62.11 | – | 559 | 85 | 2846 |
| 재파일럿 20스텝 | 63.22 | +1.11 | 569 | 94 | 2911 |
| run1 100스텝 | 62.89 | +0.78 | 566 | 87 | 2797 |

- 점수 +0.78 → 베이스라인을 다시 돌렸을 때의 차이(±1.45)보다 작아 향상으로 보기 어려움
- 잘린 응답 85 → 87로 변화 없음
  - 87개 중 54개는 베이스라인에서도 잘린 문제임
  - 나머지는 샘플링에 따라 바뀌는 정도의 차이임
- 사전에 정한 기준(MMMU 잘림 70개 미만, 점수 +2 이상) 둘 다 미달

## 4. 판단
- 지금 설정으로는 반복 루프(잘림)가 줄지 않음 → 학습 중 지표와 평가 결과 모두 같은 결론
- 2에폭(390스텝)까지 더 돌리려면 약 33시간 필요. 지금까지 개선 조짐이 없어 그대로 이어서 돌릴 근거는 약함
- 같은 설정으로 계속하기보다는 방향을 바꾸는 게 맞다고 판단함

## 5. 다음 단계 후보 (논의 필요)
- 잘림 감점 강화: −0.5보다 크게 하거나 길이 패널티를 추가
- 데이터 구성 변경: 잘리기 쉬운 문제 위주로 학습
- rejection sampling SFT: 모델 자신의 응답 중 잘리지 않고 끝난 정답 응답만 모아 SFT를 먼저 하고, 그 뒤에 GRPO

## 6. 참고 (코드 관련)
- 체크포인트에서 재개하면 `trainer_state.json`에 저장된 `save_steps` 값이 쓰이고, 명령줄의 `--save_steps`는 무시됨
- 이번에는 재파일럿 값(1000)이 그대로 쓰여 25/50/75스텝 체크포인트가 저장되지 않음. 마지막 `checkpoint-100`만 남음
- 다음에 재개할 때는 시작 전에 체크포인트의 `trainer_state.json`에서 `save_steps`를 수정해야 함
